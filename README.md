# フランちゃん — Birthday Website

黒×ピンクに、可愛い手書き風の日本語フォントと上品なセリフ体を組み合わせた誕生日サイトです。

## 使い方
1. `images/photo1.jpg`〜`photo6.jpg` を自分の写真6枚に置き換えてください（ファイル名はそのまま）。
2. 音楽を使うなら `audio/birthday.mp3` を追加してください。音楽はボタンを押すと再生します。
3. `index.html` をブラウザで開きます。
4. GitHub Pagesでは、このフォルダ内のファイルをリポジトリのルートにアップロードしてください。

## 内容
- オープニング画面
- 可愛いフォントの誕生日ヒーロー
- 手紙のタイプライター演出
- 写真6枚のギャラリーと拡大表示
- ボタンで開く10個のメッセージ
- 19歳のお祝いエンディング

サイト内で使用する名前は「フランちゃん」のみです。
